How it works

Built for the way the work actually goes

Three things that separate a working instrument from a static report.

Interactive exploration

Click any bar, slice or row to drill straight through to the applications behind it. Every visualisation is a gateway to the underlying record, not a dead end.

Real-time filtering

Filter by applicant, firm, examiner, art unit, CPC subclass, entity status or date range — in any combination. Results recompute as you go.

Primary-source data

Built directly on USPTO bulk data and the prosecution documents themselves, refreshed as new records publish. Nothing is invented; everything traces back.

Firm reporting · opt in

Aggregate composition reporting for your own firm

Firms that opt in can run aggregate composition reports across their own signing practitioners, for client audits and Mansfield-style reporting. Firm-level aggregates only — never published attributes about named individuals. Classifications are model-generated and are suitable for statistical work, not for judgements about any one person.
